# Coomer Mobile Page

This is just a front end simple page to distribute coomer android mobile app<br>
At current point I wish to keep the source code private and just distribute an APK.<br>

[Go to pages site](https://somesnakeguy.github.io/coomer_mobile_pages/)

## Local Environment Setup
* `npm install`
* `npm install -g @builder.io/cli`
* `npm run dev`
