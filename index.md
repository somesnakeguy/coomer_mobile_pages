# Intro

This is an android only app for browsing and navigating [coomer.st](coomer.st).

It currently supports all site basic functionality such as browsing creators/posts and favoriting them.

But is also introduces new functiuonality such as thumnails for videos and gallery view for images.

The app is currently mostly stable but may have bugs here or there.
